\## Description

Console application in Java to manage clients, books, and loans

for a library. In-memory storage (ArrayList).



\## How to run

1\. Open the project in NetBeans

2\. Build with Maven

3\. Run Main.java



\## Features

\- Client CRUD

\- Book CRUD

\- Loan registration and returns
